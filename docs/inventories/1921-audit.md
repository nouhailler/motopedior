# Audit préalable — année 1921

Audit du 7 novembre 2026, avant insertion : catalogue de 70 véhicules, 51 constructeurs, trois lots documentaires (1890–1900, 1901–1910, 1911–1920), dont 119 références dans le dernier lot. Les périodes d’origine et les archives sont conservées. Les 38 annotations de la liste américaine restent non vérifiées et ne sont pas des dates de construction.

Architecture examinée : React 19, Vite 6, Tailwind 4, Workbox, idb/IndexedDB v2, domaine historique normalisé schéma 2. Tables véhicules, constructeurs, marques, sources, redirections, historiques, archives et lots de recherche. Les variantes et versions de compétition sont reliées à un parent ; les générations sont décrites sans table indépendante. Moteur et constructeur peuvent être distingués dans les détails mécaniques optionnels.

Les sources portent fiabilité A–D, type, URL, auteur/organisme, consultation et champs confirmés. Les assertions au champ et contradictions permettent une revue vérifiée conditionnelle. Les dates typées séparent conception, brevet, prototype, production, vente, présentation et exemplaire documenté. La commercialisation n’est pas une construction. Les inconnues sont nulles et les conflits conservés. La datation du premier exemplaire n’est pas déduite du millésime.

Les doublons sont contrôlés par identifiant, constructeur, nom/alias normalisé, variante, moteur et dates ; aucune fusion automatique. Les familles présentes à surveiller en 1921 sont notamment Harley F, Triumph H, FN Four, Nimbus, Garelli 350, Motosacoche et Royal Enfield. Un nouveau millésime ne justifie pas une nouvelle famille.

Les imports JSON sont atomiques, CSV/JSON préservent les extensions. La migration éditoriale est additive, sauvegarde l’état précédent et préserve les décisions locales ; les annotations ajoutées aux lots existants sont idempotentes. La suite actuelle comporte 101 tests (96 JavaScript et 5 Python). Les filtres portent sur année, constructeur, pays, cylindrée, type moteur, catégorie, usage, statut et confiance.

Extension nécessaire : preuves de construction annuelle rattachées à une fiche existante. Une table optionnelle d’attestations conservera date typée, véhicule, source, confiance et note sans réécrire les 70 véhicules. Les filtres et compteurs pourront l’utiliser pour 1921. Les caractéristiques anciennes ne seront pas projetées sur une nouvelle année sans preuve ; les spécifications divergentes d’une autre génération nécessiteront une variante documentée. Aucune évolution de version physique IndexedDB n’est nécessaire pour ces extensions conservées dans l’inventaire JSON.

Limites : catalogue non exhaustif ; candidats incomplets, noms commerciaux et désignations internes parfois ambigus. Les notices de musée datent parfois un objet restauré ou un millésime : leur portée sera signalée. Les conflits Peugeot, Golem et les datations anciennes ne sont pas arbitrés sur simple intuition. L’absence de document n’est pas une preuve d’inexistence.
